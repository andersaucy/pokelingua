# Pokélingua

A living atlas of Pokémon localization: names, releases, dubs, scripts, regional decisions, and the cultural history around them.

## What this first edition includes

- an explorable locale index
- a featured South Korea chapter
- dated notes on the 2016 Hong Kong Pikachu naming controversy
- Spanish-for-Spain and Latin American Spanish distinctions
- Brazilian and European Portuguese distinctions
- a filterable global milestone timeline
- visible sourcing and editorial principles

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

The project uses Next.js and is ready to import into Vercel.

## Editorial status

Pokélingua is an independent research project. This repository currently contains a designed pilot rather than a comprehensive database. Dates and naming claims should be linked to official sources or clearly marked secondary evidence as the archive grows.
